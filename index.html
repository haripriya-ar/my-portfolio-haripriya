01

Decoder-Disagreement-Guided Selective Medical Knowledge Retrieval for Low-Resource Indic Speech Recognition

A Bodo Proxy-Language Study

Overview

Explores uncertainty-aware automatic speech recognition for low-resource languages, focusing on the recognition of medical terminology. The framework compares CTC and RNN-T decoding outputs from IndicConformer-600M to estimate recognition uncertainty. When decoder disagreement exceeds a predefined threshold, the system selectively invokes a medical knowledge retrieval mechanism based on WHO ICD-11 terminology to generate and rank alternative hypotheses.

Key Contributions

  • Decoder-disagreement-based uncertainty estimation
  • Selective routing between direct recognition and knowledge-guided processing
  • English medical knowledge base using WHO ICD-11
  • Candidate generation, retrieval, and ranking pipeline
  • Bodo-to-English and Bodo-to-Malayalam translation using IndicTrans2

Results

19.88% WER (RNN-T baseline)
6.15% CER (RNN-T baseline)
89.4% Top-3 recovery (synthetic retrieval eval)

Note: The proposed pipeline matched the RNN-T baseline WER/CER. The 89.4% figure is from a controlled synthetic character-corruption experiment, not live speech evaluation.

Python IndicConformer-600M CTC / RNN-T Levenshtein Distance WHO ICD-11 API IndicTrans2 Hugging Face NLP

Reinforcement Learning · Optimization
02

Constraint-Aware Reinforcement Learning for Dynamic University Course Timetable Scheduling and Schedule Repair

Overview

Developed a constraint-aware reinforcement learning framework for repairing university course timetables when unexpected disruptions occur — faculty unavailability, room conflicts, time-slot clashes, and enrollment changes. The system formulates timetable repair as a Markov Decision Process and employs a Double Deep Q-Network (Double DQN) agent to select appropriate repair actions while preserving unaffected assignments.

Key Contributions

  • RL environment for dynamic timetable repair
  • 161 possible repair actions
  • 8 hard constraints, 4 soft constraints
  • Constraint-aware reward calculation & action masking
  • Comparison with Greedy Repair and Minimum Perturbation Repair
  • 1,000 simulated disruption scenarios

Experimental Results

58.67% Repair success rate
1.92 Mean remaining hard-constraint violations
100% Preservation of unaffected assignments
714.5 ms Mean inference time (Double DQN)

Results evaluated on a 200-course synthetic timetable with 1,000 disruption scenarios. Performance was comparable to heuristic baselines in repair success rate.

Python PyTorch Double DQN MDP Action Masking NumPy Pandas Matplotlib

03

LLM-Enhanced Explainable Biomedical Relation Extraction: Pipeline vs Joint Models with RAG-Based Evidence Retrieval

Overview

Developed an advanced biomedical NLP system using transformer-based language models (BioBERT) for named entity recognition and relation extraction. Compared pipeline and joint learning architectures, and integrated Retrieval-Augmented Generation (RAG) with ChromaDB for evidence retrieval. Added explainability layers using SHAP, LIME, and attention visualization, with LLM-powered clinical explanation generation.

Key Contributions

  • Biomedical NER using BioBERT
  • Drug–Disease Relation Extraction
  • Pipeline vs Joint Learning comparison
  • RAG with ChromaDB vector database
  • Explainable AI (SHAP & LIME)
  • Attention visualization
  • LLM-powered clinical explanations
  • Interactive Gradio deployment
